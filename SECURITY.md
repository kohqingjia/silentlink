# Security and research data

Public source does not make sensor recordings public. Report vulnerabilities privately through the repository owner's GitHub profile; do not attach participant recordings or credentials to issues.

Rotate a device key by revoking its device label and issuing a replacement. Revoke immediately after accidental exposure. All keys for one owner can access that owner's dataset. Do not deploy this personal-research milestone as a multi-tenant clinical service without further security, privacy and operational review.

The server uses HTTPS at Caddy, hashed high-entropy device tokens, ownership checks, body/concurrency/rate limits, protected storage and mode-restricted backups. Local-only mode is the iPhone default. No microphone permission, LLM provider, prediction endpoint or analytics service is configured.
